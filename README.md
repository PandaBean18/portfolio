# Developer Portfolio

A dynamic, interactive portfolio showcasing various software and hardware engineering projects.

## Overview

This portfolio replaces a traditional static website with a bespoke **Matrix Hub** visual interface. It serves as a central index to explore case studies covering fullstack applications, machine learning systems, and embedded hardware.

## Getting Started

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone git@github.com:PandaBean18/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
